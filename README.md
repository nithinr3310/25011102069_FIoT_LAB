# Foundations of IoT + Lab

Repository for the Foundations of Internet of Things laboratory assessments.

## Platforms
- `8051/` — 8051-based experiments (to be added if applicable).
- `STM32/` — STM32-based experiments.

## Experiment documentation
Each experiment folder will contain its assessment-specific `README.md`, circuit diagram, source files, and the relevant IDE/project configuration.

> This repository is being assembled from the assessment sheets. Firmware and generated project files will be added and verified experiment by experiment.
